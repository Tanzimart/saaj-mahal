# SAAJ MAHAL — Free Website

This is a mobile-first static e-commerce starter website for SAAJ MAHAL (সাজ মহল).

## Included
- Premium maroon/gold fashion branding
- Responsive mobile/desktop homepage
- Category navigation
- Featured product cards
- Demo cart drawer
- WUAZE store link
- About / brand story
- Delivery / support section
- Existing SAAJ MAHAL logo and banner assets

## Important before publishing
1. Replace the demo product names/prices/images in `index.html`.
2. Add your real WhatsApp/phone number where indicated.
3. Add your real delivery, payment, return and exchange policies.
4. For a full production checkout/payment system, connect a proper e-commerce backend or keep ordering through the WUAZE store.

## Free publishing
Upload the contents of this folder to any static-site host that offers a free tier, or use GitHub Pages. The site itself has no paid code/theme dependency.
